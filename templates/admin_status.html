Changing a setting

  1. Open your service in the Render dashboard.
  2. Go to Environment in the left-hand menu.
  3. Add the variable exactly as spelled above. Names are case-sensitive.
  4. Save. Render redeploys automatically; wait for it to finish.
  5. Come back to this page. It should now read ON.

Nothing takes effect until the redeploy completes. If this page still says OFF afterwards, the name or value is wrong rather than the feature being broken.
